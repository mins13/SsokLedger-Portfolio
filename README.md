# 🧾 쏙장부 | SsokLedger

영수증을 AI로 분석하고, 확인한 내용을 장부에 연결해 관리하는 웹·앱 서비스입니다.

> 이 저장소는 쏙장부의 기능과 개발 경험을 소개하는 포트폴리오입니다.
> 서비스 소스 코드는 비공개로 관리합니다.

## 📌 프로젝트 정보

- **개발 기간:** 2026.09 ~ 진행 중
- **개발 형태:** 개인 프로젝트
- **담당 역할:** 기획 · UI 설계 · 프론트엔드 · 백엔드 · 웹 배포
- **진행 상태:** 웹 배포 완료 / Android 앱 비공개 테스트 진행 중

## 💡 개발 배경

단체 행사 예산 정산 중 계약서 금액을 잘못 확인해
약 60만 원의 예산 오차를 겪었습니다.

이 경험을 계기로 수기 입력과 반복 확인의 부담을 줄이고자
영수증 인식과 장부 관리를 연결하는 쏙장부를 개발했습니다.

AI 인식 결과를 사용자가 확인·수정할 수 있도록 구성해,
자동화 과정에서 발생할 수 있는 오류에도 대응하고자 했습니다.

## ✨ 주요 기능

### 🧾 영수증 관리
- 영수증 이미지 업로드 및 수동 등록

- 기간·키워드 등 조건별 거래 검색
- 페이지네이션 및 정렬
- 수입·지출 및 예산 현황 조회

### 🔐 사용자 인증 및 접근 제어
- Google 로그인 및 JWT 기반 인증

## 🔍 주요 기술 과제

### 1. 불완전한 AI 인식 결과 처리

**과제**

영수증 분석 결과에 날짜나 수입·지출 유형이 누락되거나,
신뢰도가 낮은 응답이 반환될 수 있었습니다.
이 결과를 장부에 반영하기 전에 검증하는 절차가 필요했습니다.

**구현**

- 필수 정보의 누락 여부 검사
- 신뢰도 값이 없거나 0.80 미만이면 검토 대상으로 분류
- 검토가 필요한 사유를 함께 저장
- 사용자가 내용을 확인·수정한 뒤 확정하는 흐름 구현

**배운 점**

외부 AI 연동에서는 응답을 받는 것뿐 아니라,
결과를 검증하고 사용자가 바로잡을 수 있는 절차까지 설계해야 한다는 점을 배웠습니다.

### 2. 영수증과 거래 데이터의 일관성 유지

**과제**

영수증에서 장부 거래를 생성한 이후에도
사용자가 인식 내용을 수정할 수 있어 두 데이터의 연결 처리가 필요했습니다.

**구현**

- 영수증 확정 시 연결된 거래의 존재 여부 확인
- 연결 거래가 없으면 신규 생성
- 기존 거래가 있으면 확정한 영수증 내용과 동기화

### 3. 다양한 거래 검색 조건 처리

**과제**

기간·키워드 등의 선택적 검색 조건과
페이지네이션·정렬을 함께 처리해야 했습니다.

**구현**

- JPA Specification으로 검색 조건 조합
- 시작일과 종료일의 순서 검증
- 검색어 길이 최대 100자 제한
- 페이지 크기 최대 100건 제한
- 정렬 가능한 필드 제한
- 공통 페이지 응답 형식 적용
